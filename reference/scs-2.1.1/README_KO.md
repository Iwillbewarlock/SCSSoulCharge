# SpellCastingStaff 2.1.1

지팡이에 지정한 주문을 종류·강화 단계별로 기억하고, 다시 장착하면 자동으로 복원합니다. 이번 배포명은 2.1.1이며 내부 버전은 2.1.1, SKSE 플러그인 버전은 2.1.1.0입니다.

## 사용 방식

- 지팡이를 장착한 뒤 마법 또는 즐겨찾기 메뉴에서 주문을 선택해 지정합니다.
- 같은 주문을 다시 선택하면 그 지팡이의 지정과 기억이 해제됩니다. 한 번 더 선택하면 다시 지정됩니다.
- 지팡이를 벗으면 원래 이름으로 돌아오지만 주문 기억은 유지됩니다. 재장착하면 조용히 복원합니다.
- 다른 종류 또는 강화 단계의 지팡이는 각각 다른 주문을 기억합니다. 같은 기본 무기 폼을 사용하는 복제 아이템은 기억을 공유합니다.
- 기억은 SKSE 코세이브에 저장됩니다. 저장 파일과 함께 해당 .skse 파일도 유지하세요.
- 일시정지된 인벤토리·즐겨찾기에서 재장착하면 이름을 먼저 갱신합니다. 재장착에 따른 실제 주문 상태·버프·ENCH·장비 동기화는 일시정지 해제 뒤 처리합니다. 직접 주문 선택은 기존 지정 경로를 사용합니다.
- 특수 지팡이는 한 번에 하나를 사용하는 구조입니다. 공유 ENCH에는 현재 장착 지팡이에 맞춘 시전 방식과 충전 시간만 반영합니다.

## 지원 대상

Skyrim SE 1.5.97.0, Steam 1.6.1170.0, Steam 1.7.104.0을 명시적으로 지원합니다. 다른 1.6/1.7 버전, GOG, VR은 지원하지 않습니다. 실행 파일 버전에 맞는 SKSE와 Address Library를 사용하세요.

## 빌드 및 설치

1. 이 소스를 새 폴더에 풀고 VS2022/MSVC 14.44, vcpkg 매니페스트, x64-windows-static-md 환경에서 Release로 빌드합니다. 동봉 vendor/CommonLibSSE-NG는 1.7.104 지원을 보완한 버전이므로 일반 패키지로 교체하지 마세요.
2. 기존 VCPKG_ROOT 환경 설정을 사용합니다. 개발자 명령 프롬프트에서는 `cmake --preset release` 후 `cmake --build build/release`로 빌드할 수 있습니다.
3. 생성한 SpellCastingStaff.dll을 Data/SKSE/Plugins에 설치합니다. 시작 로그가 SpellCastingStaff v2.1.1인지 확인합니다.
4. 기존 모드의 메시·텍스처 등 리소스를 유지합니다. Reference/SpellCastingStaff.esp는 변경하지 않은 영어판 참고 ESP입니다. 개인용 모델/번역 ESP를 이 파일로 무조건 덮어쓸 필요는 없습니다.
5. 영어판은 config/SpellCastingStaff.ini를 사용합니다. 한국어판은 config/SpellCastingStaff_Korean.ini를 **SpellCastingStaff.ini로 이름을 바꿔** Data/SKSE/Plugins에 설치합니다. 두 파일을 합치지 말고 하나만 선택하세요.
6. INI 수정은 게임을 완전히 종료하고 다시 실행해야 적용됩니다. 번역할 수 있는 알림과 설정 설명을 두 언어로 제공합니다. INI의 언어는 ESP의 아이템 이름이나 진단 로그 언어를 바꾸지 않습니다.

로그는 실제 문서 폴더(OneDrive 리디렉션 포함)의 My Games/Skyrim Special Edition/SKSE/SpellCastingStaff_<런타임>.log에 기록됩니다. 상세 로그는 bVerboseLog=1, 평상시는 0입니다. 진단 단축키 기본값은 0(사용 안 함), 64를 넣으면 F6입니다.

## 확인 범위와 제한

사용자는 직전 기능 수정판을 SE 1.5.97에서 빌드하고 즐겨찾기 이름 갱신 성공을 확인했습니다. 제공 로그에서는 종류별 주문 복원과 치유/불길/화염 화살 시전이 확인됩니다. **2.1.1 전체 Windows DLL 빌드와 인게임 재시험은 이 환경에서 수행하지 않았습니다.** 소스에는 DLL과 게임 실행 파일, Address Library 데이터, 모드 메시·텍스처가 포함되지 않습니다.

Variable08을 다른 용도로 사용하는 모드와는 충돌할 수 있습니다. 필수 메뉴 훅 설치 실패 시 기능을 비활성화하고 안내하며, 선택적 소환무기 복원 훅은 안전 검증을 통과하지 못하면 설치하지 않습니다. 임의의 E9 점프나 알 수 없는 메뉴 훅을 무조건 연결하지 않습니다. 모든 모드 조합과 장시간 CTD 부재를 보장하지 않습니다.

이번 변경과 검수 결과는 CHANGELOG.md 및 docs/REVIEW_2.1.1_KO.md를 참고하세요. 과거 수정 기록은 docs/history에 보존했습니다. 선택적 MSVC 경로 제거 옵션 SCS_TRIM_RELEASE_FILE_PATHS는 기본 꺼짐이며, 켜서 배포하려면 실제 DLL을 별도로 확인하세요.

## 2.1.1 검수 보완판 (ReviewFix1)

사용자가 AE 1.7.104에서 정상 작동을 확인했다고 보고했습니다. SE 1.5.97의 이전 확인과 함께 기록하되, 이번 이름 미리보기의 1.6.1170 실사용 검증은 아직 별도입니다. 사용자 요청으로 AE 기능 제한은 추가하지 않았습니다. 이번 보완판 자체의 Windows 빌드/인게임 재시험은 수행하지 않았습니다.

- validateLoadedPending_를 atomic으로 변경하고 release store / acq_rel exchange를 사용합니다. 컨트롤러 전체의 동시 접근 안전성을 보증하는 변경은 아닙니다.
- OwnsDualCastEffect에서 kOther/주문 존재/단발형 조건을 먼저 확인하여 불필요한 캐스터 조회를 줄였습니다. 이후 소유권 판정은 유지합니다.
- LICENSE의 누락된 Permission is hereby granted 문구를 복원했습니다. Nexus 권한 설정은 확인하거나 변경하지 않았습니다.
- 중복 선택 300ms 제한과 기억 기능 OFF 옵션은 추가하지 않았습니다. 두 언어 INI와 ESP는 직전 보완판과 설정값이 동일합니다.
- 시작 로그에서 2.1.1로 구분합니다. 내부 버전은 2.1.1.0입니다.

공개 DLL의 소스 경로 제거 옵션을 사용하려면 개발자 명령 프롬프트에서 `cmake --preset release -DSCS_TRIM_RELEASE_FILE_PATHS=ON`으로 구성한 뒤 `cmake --build build/release --clean-first`로 다시 빌드하세요. /d1trimfile은 비공식 옵션이므로 빌드 결과와 DLL에 로컬 경로가 남았는지를 확인해야 합니다. PDB는 공개 패키지에 포함하지 않는 것이 좋습니다. 이 옵션은 DLL 안의 모든 가능한 경로 문자열 제거를 보장하지 않습니다.
